Welcome to `CrSb0001/PVZ_TRAVEL_SAVEFILES_LEVELTESTS`! This is a Github repository for documenting custom-made PvZ Travel levels dedicated to testing how
different zombies interact with each other, as well as save files at different points of progress.

Note that not all custom levels nor all save files submitted will make it into the repository, as well as any pull requests regarding level/save file decoding (as of right now).

---

## Guidelines for submitting a custom level:


### For zombie levels:

- [ ] Does it test the mechanics of a specific zombie?
    - For the Beetle Car Zombie, Necromancer Zombie, and Spirit Guardian Zombie, the level can use more than 1 zombie type as long as it
      doesn't jointly focus on another zombie's mechanic.
- [ ] If the zombie has multiple unique mechanics, is it clear which mechanic is being tested?
- [ ] Does the level clearly incorporate the mechanic into its core gameplay loop?


### For plant levels:

- [ ] Does it show a specific synergy this plant has with a certain plant/against a certain zombie?
- [ ] If the plant has different use-cases, does the level incorporate those different uses into its core gameplay loop?
- [ ] (Aipoi only) Does the level show the effects of Chilling/Freezing Wind or Heat Wave on an Aipoi?
    - [ ] Chilling Wind
    - [ ] Freezing Wind
    - [ ] Heat Wave
